# terraform-aws-jaws-network

Terraform modules for a small, low-cost AWS network: a VPC with public and optional private subnets, and a NAT instance

The modules are on their way: this is the initial scaffold. Once the first
version is released they are published on the
[Terraform Registry](https://registry.terraform.io/modules/jwallace145/jaws-network/aws/latest)
as `jwallace145/jaws-network/aws`.
